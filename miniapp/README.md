# 湘超微信小程序版

由 `../高保真原型` 移植的 Taro + React + TypeScript 小程序。当前是**纯只读 MVP**：看赛程赛果、积分射手、球队球员、资讯海报，选主队和开赛提醒，不含登录、竞猜、投票、评论、助威。

## 运行

```bash
npm install
npm run dev:weapp   # 产物在 dist/，watch 模式
```

用微信开发者工具打开本目录（`miniapp/`），它会读取 `project.config.json` 并加载 `dist/`。
当前 `appid` 是开发者工具的测试号 `wx92488c445753f70a`，只能本地预览；正式上线前换成自己的小程序 AppID。

> 本机 Homebrew 的默认 Node 26 链接损坏（缺 `libsimdjson.34.dylib`），上面命令需要用 Node 22：
> `export PATH=/opt/homebrew/opt/node@22/bin:$PATH`。换一台正常机器可忽略。

H5 预览（仅用于看布局，不是发布目标）：

```bash
npm run build:h5
cd dist-h5 && python3 -m http.server 4174
```

## 已实现

- 4 个主 Tab：赛事、数据、发现、我的
- 首次进入：选主队引导，可跳过
- 比赛详情：真实比分、场地、开球时间、报名名单、分享海报
- 真实数据：2026 湘超 13 轮 91 场常规赛 + 12 场淘汰赛（截至 11 月 15 日），14 队 598 名报名球员，官方队徽
- 球队详情：排名走势、排名/积分/战绩、赛程、阵容、城市名片
- 球员详情：真实号码、进球、点球、黄牌、红牌
- 数据页：积分榜、射手榜、球队、赛季模型推演
- 发现页：官方公开报道摘要
- 我的：主队选择、开赛提醒（复制 ICS）、消息中心、隐私与数据来源
- 搜索、淘汰赛对阵
- 模型推演统一标注“仅供娱乐，不构成投注建议”

## 数据来源

- 赛事、比分、场地、开球时间、淘汰赛对阵：足球中国 / 湖南省足球联赛（`soccer.thecfa.info`）
- 报名名单、球员号码、赛季进球与红黄牌：同站球队名单接口
- 更新脚本：仓库根目录 `node scripts/import-cfa.mjs`（会重写 `src/data/season.json`、`src/data/logos.ts`、`src/assets/teams/` 和云函数数据）
- 官方未公开每场进球时间、首发十一人、控球/射门等技术统计，相关页面显示“官方未公布”，不生成假数据

## 线上数据更新（微信云开发）

正式版不建数据库，用一个云函数返回赛程快照，更新数据不用重新提审：

1. 微信开发者工具开通云开发，记下环境 ID。
2. `.env.production` 填 `TARO_APP_CLOUD_ENV=<环境 ID>`，重新构建。
3. 开发者工具里右键 `cloudfunctions/league` →「上传并部署：云端安装依赖」。
4. 以后更新：`node scripts/import-cfa.mjs`，再重新部署 `league` 云函数。
5. 小程序启动时优先调云函数，失败回退到 HTTP 接口或内置的 `src/data/season.json`。

云函数只返回公开赛程数据，不含任何用户信息。未配置云环境时小程序直接用构建时的内置数据。

## 后端（可选，演示用）

`../server` 有一个 Node API 和赛果管理后台，仅用于本地演示，不是上线依赖：

```bash
cd ../server
npm install
npm run seed
npm start
# http://127.0.0.1:8787/admin
```

联调时在 `miniapp/.env.development` 配置 `TARO_APP_API=http://127.0.0.1:8787`，改完重启 watch。开发者工具需关闭“校验合法域名”（`urlCheck` 已设为 `false`）。

## 已知限制

- 开赛提醒用「复制日历内容」代替直接写日历，消息中心是本地提醒，未接订阅消息。
- 海报用小程序 Canvas 2D 生成，保存相册需要用户授权。
- 资讯只做公开报道摘要，不转载全文；集锦、文旅、票务未接入。
- MVP 隐藏的登录/竞猜/评论代码仍在仓库里由 `src/config.ts` 的 `MVP` 开关控制，恢复前需先补后端与内容安全。

## 上线前要做的

1. 注册个人主体小程序，拿到正式 AppID；如需“湘超”名称或官方队徽商用授权，先取得授权或用备选名/自绘队徽。
2. 小程序认证、备案、选择体育赛事类目。
3. 开通云开发，部署 `league` 云函数，配置 `TARO_APP_CLOUD_ENV`。
4. 在微信后台填写隐私保护指引：不收集个人信息、无登录、无支付。
5. 用正式 AppID 真机预览，检查比分、名单、海报与提醒。
