# 湘超微信小程序版

由 `../高保真原型` 移植的 Taro + React + TypeScript 小程序。赛事核心数据来自 2026 湘超官方公开数据，页面结构和视觉沿用原型。

## 运行

```bash
npm install
npm run dev:weapp   # 产物在 dist/，watch 模式
```

用微信开发者工具打开本目录（`miniapp/`），它会读取 `project.config.json` 并加载 `dist/`。
当前 `appid` 是开发者工具的测试号 `wx92488c445753f70a`，只能本地预览/体验；正式上线前换成湘超自己的小程序 AppID。

> 本机 Homebrew 的默认 Node 26 链接损坏（缺 `libsimdjson.34.dylib`），上面命令需要用 Node 22：
> `export PATH=/opt/homebrew/opt/node@22/bin:$PATH`。换一台正常机器可忽略。

H5 预览（仅用于看布局，不是发布目标）：

```bash
npm run build:h5
cd dist-h5 && python3 -m http.server 4174
```

## 已实现

- 5 个主 Tab：赛事、数据、球迷、发现、我的
- 首次进入：选主队引导，可跳过
- 顶部标题栏：我的、数据、球迷、发现页头吸顶固定；首页滚动后收成细标题条，吸顶后纸卡片圆角仍保留
- 比分刷新：有直播比赛时每 30 秒自动拉取，首页和比赛详情支持下拉刷新
- 比赛详情：真实比分、场地、开球时间、比分竞猜、球迷投票、AI 预测、报名名单、讨论、分享海报
- 真实数据：2026 湘超 13 轮 91 场常规赛 + 12 场淘汰赛（截至 11 月 15 日），14 队 598 名报名球员，官方队徽
- 球队详情：排名走势、排名/积分/战绩、赛程、照片墙、阵容、城市名片
- 球员详情：真实号码、进球、点球、黄牌、红牌
- 数据页：积分榜、射手榜、球队、AI 赛季推演
- 球迷页：城市助威（每日 20 次）、本轮竞猜、排行榜、AI 球评助手
- 发现页：资讯、集锦占位、文旅优惠/观赛点
- 我的：本地登录、主队选择、竞猜记录、开赛提醒（复制 ICS）、推送设置、隐私协议
- 搜索、消息中心、淘汰赛推演

## 数据来源

- 赛事、比分、场地、开球时间、淘汰赛对阵：足球中国 / 湖南省足球联赛（`soccer.thecfa.info`）
- 报名名单、球员号码、赛季进球与红黄牌：同站球队名单接口
- 更新脚本：仓库根目录 `node scripts/import-cfa.mjs`（会重写 `src/data/season.json`、`src/data/logos.ts` 和 `src/assets/teams/`）
- 官方未公开每场进球时间、首发十一人、控球/射门等技术统计，相关页面已改为“官方未公布”，不再生成假数据

## 原型限制（下一版再接）

- 赛事核心数据是真实 2026 湘超数据；资讯、球迷排行、竞猜记录、评论仍是本地演示内容，尚未接真实 UGC。
- 官方未公开逐场事件/首发/技术统计，比赛详情对应页签显示“官方未公布”。
- 登录是演示登录，不请求微信手机号，也不校验验证码。
- 开赛提醒用「复制日历内容」代替直接写日历。
- 海报已用小程序 Canvas 2D 生成，保存相册需要用户授权。
- 评论只存在本地，未接内容安全审核；讨论区不再展示预置假评论。
- 未接订阅消息、微信支付、票务。
- 没有 UGC 内容审核、没有账号注销后端。

## 后端

`../server` 已有一个可运行的 Node API 和赛果管理后台：

```bash
cd ../server
npm install
npm run seed
npm start
# http://127.0.0.1:8787/admin
```

小程序启动时会请求 `../server` 的 `/api/league`，成功后用返回的比赛数据替换本地种子；请求失败则继续用本地种子。存在进行中的比赛时每 30 秒自动刷新一次，首页和比赛详情也可下拉刷新。

联调时先启动 server，再在 `miniapp/.env.development` 配置：

```bash
TARO_APP_API=http://127.0.0.1:8787
```

改完 `.env.development` 需要重启 `npm run dev:weapp`。开发者工具需要关闭“校验合法域名”（`project.config.json` 的 `urlCheck` 已设为 `false`）。正式环境改成 HTTPS API 域名，并在微信后台配置服务器域名。
