## 描述

2026 湖南省足球联赛球迷数据工具。

- 完整赛程与赛果：14 个市州代表队、常规赛 13 轮与淘汰赛两回合
- 比赛日与最近赛果：按比赛日查看当天赛程，进行中比赛优先，赛后回看结果
- 积分榜与射手榜：同分按相互战绩、净胜球、进球数排序
- 淘汰赛对阵：总比分、点球大战与晋级球队
- 球队与球员：真实报名名单、号码、进球与纪律数据
- 淘汰赛对阵页：两回合总比分、点球与晋级路径
- 本地开赛提醒：开赛前 30 分钟通知，可随时取消
- 比赛海报：本地生成，可直接分享
- 模型推演：基于历史比分与主场优势的概率预测
- 球迷账号：赛果投票、城市助威、预测排行榜、我的预测与赛后猜中反馈

浏览赛程不需要登录。登录使用 Sign in with Apple，仅用于记录投票、助威和积分；可随时在 App 内注销账号并删除数据。无广告、无评论、不收集位置或通讯录。

赛事数据来自官方公开渠道，一切以官方发布为准。本 App 与赛事主办方无隶属关系。投票不涉及投注、奖金或兑换。

## 审核备注

- 浏览赛程、榜单、对阵不需要登录；只有投票、助威和排行榜需要 Sign in with Apple。
- 账号注销在「我的 → 注销账号并删除数据」和「球迷 → 账号」中，服务端会立即删除昵称、投票、助威、积分和会话。
- 无评论、私信、社区帖或其他用户生成内容；投票只有主胜/平局/客胜三个选项。
- 投票和排行榜仅用于球迷互动，无奖金、无兑换、无现金价值，界面明确标注不构成投注建议。
- 「模型推演」的本地概率由 App 计算，仅供娱乐，不构成投注建议；中国版不包含 AI 生成内容。
- 开赛提醒为可选本地通知，首次加入提醒时请求权限。
- 队徽为 App 自绘的盾形徽章，不使用赛事官方队徽；队名、队色和赛果属于公开事实信息。
- 数据更新前显示“官方未公布”，不虚构进球时间、首发或技术统计。

## 提交流程

自动检查：

```bash
cd ios
./scripts/release-check.sh
```

1. 注册 Apple Developer Program（个人主体）。
2. 在 App Store Connect 新建 App，Bundle ID 使用 Xcode 工程里的最终 ID。
3. Apple Developer 后台开启 Sign in with Apple；Xcode 选择 Team；`APPLE_CLIENT_ID` 与 Bundle ID 一致。
4. 部署 `server/` 到 HTTPS 域名，关闭 `ALLOW_DEV_AUTH`，备份 `fans.json`。
5. 服务端已提供 `/privacy.html` 和 `/support.html`，把这两个 URL 填到 App Store Connect。
6. 填写元数据和隐私标签，上传 6 张截图，Xcode Archive 上传：

```bash
XC_API_BASE_URL=https://api.your-domain.com xcodebuild archive \
  -project XiangChao.xcodeproj -scheme XiangChao -configuration Release \
  -destination 'generic/platform=iOS' -archivePath build/XiangChao.xcarchive
```
7. 出口合规选择“未使用加密”（`ITSAppUsesNonExemptEncryption` 已为 false）。
8. 提交审核。
